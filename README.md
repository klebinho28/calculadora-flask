# 🧮 Calculadora Flask

Sistema web de calculadora desenvolvido utilizando Python e Flask.

## 🚀 Funcionalidades

* Soma
* Subtração
* Multiplicação
* Divisão

## 🛠️ Tecnologias Utilizadas

* Python
* Flask
* HTML5
* CSS3

## 📚 Objetivo do Projeto

O projeto foi desenvolvido com foco em lógica de programação, rotas backend, formulários HTML e manipulação de dados enviados pelo usuário.

## ▶️ Como executar o projeto

```bash
pip install flask
python3 app.py
```
